# Cartoon Audio Short Studio

An AI-assisted production workspace for original vertical cartoon shorts.

## Target output
- 1080 × 1920 (9:16), 30 fps
- Duration follows the supplied voiceover
- Original stories, characters, environments, and shot design
- Voiceover remains unchanged; picture is timed to narration
- Music and sound effects are mixed to the specification in the production skill
- MP4 export with visual/audio quality checks

## Repository status
This repository is the project workspace. The Agent Skill is installed at
`.agents/skills/cartoon-audio-short/SKILL.md`.

**Rendering is not ready yet.** The uploaded skill references a `kit/` animation
engine, but that engine was not included with the original upload. The project
will implement and test the missing renderer before claiming end-to-end MP4
production.

## Quick start
1. Open this repository in GitHub Codespaces.
2. Read [Codespaces setup](docs/SETUP_CODESPACES.md).
3. Read [architecture and milestones](docs/ARCHITECTURE.md).
4. Use the Agent Skill in `.agents/skills/cartoon-audio-short/` with a
   Skills-compatible agent environment.

## Cost and resource notes
Codespaces compute/storage and any external AI or audio services may incur
charges or usage limits. Do not enable paid services or larger machine types
without checking the cost first.

## Safety and originality
Create original characters and scenes. Do not reproduce another creator's
video shot-for-shot, use living real people as characters, or use brand
mascots/logos. Verify historical claims before presenting them as fact.
